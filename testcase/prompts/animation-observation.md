# 動畫與執行觀測驗收

範例需求：讓機器人在既有的家中循環走動，輸出動畫 GLB、可播放 GIF 與靜態預覽，並驗證步態與避障。使用隔離工作區，避免覆寫既有任務。

手動驗收要點：

1. 對照 run、attempt、graph 節點及實際 provider；重試必須分開，不混成同一次。
2. stdout 若只有 trust warning，核對相同 session 的工具進度與時間；警告不代表阻塞，不自動修改 trust。
3. 非串流最終結果尚未回報時，未知 token 不能顯示 0；session 恢復須有精確歸屬與 partial 標示。
4. 同 message ID 的重複紀錄不能加總；final aggregate 與 session 部分用量不能雙算。
5. 確認主要 GIF 路徑、非零檔案、GIF 標頭及多幀結構，再於正式產物清單開啟，驗證播放、循環及重新載入。不要拿 log 的小型測試 GIF 冒充交付。
6. 活動、產物存在、單節點成功與 graph 完成分開；沒有有效 graph-result 就不能宣稱整圖完成，也不能由圖結果冒稱七階段交付。

此檔是觀測缺口驗收清單，不加入既有分類矩陣，此清單不會自行啟動模型呼叫。
